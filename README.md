# Kiki's Place Website

Responsive website for Kiki's Place, a 24-hour fast food restaurant in Ruiru.

**Live site:** https://eng-zac-tech.github.io/kikis-place-website/

## Features
- Canvas ember particle effect
- 3D dish carousel
- Masonry gallery
- WhatsApp checkout
- Google Maps embed
- Dark/light theme toggle
- Grab & Go branch modal

## Tech
HTML, CSS, JavaScript, Canvas

## Run locally
Open `index.html` in your browser.
